# 配信収益の手取り・申告ライン計算

静的 HTML/JS のみ。入力は端末の外に送らない。令和8年分（2026年の収入）専用。

- テスト: `npm test`（Node 組み込みの test runner）
- 見る: `index.html` をブラウザで開く
- 公開: GitHub Pages（Settings → Pages → main / root）。公開はオーナーが実行
- 数字の根拠: business リポジトリ `01_調査/2026-11-06_本命Webツール前提確認.md`。数字を変えるときは `calc.js` の CONST と画面の出典表を同時に直す
